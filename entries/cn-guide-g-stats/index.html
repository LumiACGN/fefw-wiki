来源摘要

力量、魔力、速度、技巧、防守、魔防、幸运、魅力各管什么，攻速怎么算、什么时候能追击；魅力的主要用途是提高计略命中

角色能力说明：每项属性是干什么的

角色面板上有两组数值：一组是升级会成长的「基础能力」，一组是由基础能力、武器和技能算出来的「战斗能力」。战斗时真正起作用的是后者。下面按游戏内说明整理，并补充了在本站其他页面能看到的相关技能和道具。

基础能力（升级时成长）

| 能力 | 作用 | 补充 | | HP | 体力，降到 0 就会撤退 | | | 力量 | 物理攻击（剑、枪、斧、弓、手甲）造成的伤害 | | | 魔力 | 魔法攻击造成的伤害 | | | 速度 | 影响攻速和回避 | 攻速比对手高 4 以上可以追击 | | 技巧 | 影响命中率和必杀出现的频率 | | | 防守 | 减少受到的物理伤害 | | | 魔防 | 减少受到的魔法伤害 | | | 幸运 | 效果比较杂，其中一项是降低被对手打出必杀的几率 | 不少技能按幸运计算发动率，如「好机+」 | | 魅力 | 提高计略的命中率 | 少数技能和装备也按魅力计算发动率，见下文 |

魅力到底有什么用

魅力的主要作用只有一个：让「计略」更容易命中。计略是带上军团兵之后才能用的特殊攻击，用计略攻击时对手不会反击，自己也不会掉血，被包围或者不想冒险时很好用。魅力越高，计略越不容易被躲开。

除此之外，也有技能和装备按魅力来算发动几率：

- 战场剧作家：周围 2 格内的友军战斗时，有（该友军魅力÷2）% 几率让友军必杀回避+10 - 魅惑面具：战斗时有（魅力÷2）% 几率发动，让敌人命中-20 - 神舞：魅力+10 - 黑珍珠：使用后魅力永久+2

所以：常用计略、或者想带上面这些技能装备的角色，魅力才值得在意。只打普通攻击的角色，魅力低一点问题不大。舞者、神乐神将这类职业魅力成长修正最高；主角四人和欧露赫露的个人魅力成长也很高。

> 目前没有找到魅力会影响挖角交涉、好感度或支援的资料。如果你在游戏里发现了别的作用，欢迎用页脚的「复制反馈模板」告诉站长。

战斗能力（实际参战的数值）

| 数值 | 怎么来 | 作用 | | 攻击 | 武器威力 + 力量（魔法为魔力）+ 各种加成 | 打到对手身上的伤害 | | 攻速 | 速度 − （重量 − 体格，最少按 0 算） | 比对手高 4 以上时追击，多打一次 | | 命中 | 武器命中 + 技巧 + 战技 / 特技 / 支援加成 | 实际命中率 = 自己的命中 − 对手的回避 | | 必杀 | 武器必杀 +（技巧 + 幸运）÷ 2 + 战技 / 特技 / 支援加成 | 实际必杀率 = 自己的必杀 − 对手的必杀回避；必杀造成 3 倍伤害 | | 回避 | 攻速 + 战技 / 特技 / 支援 / 地形加成（所以重量超出体格也会拖低回避） | 降低对手的命中率 | | 必杀回避 | 幸运 + 特技 / 支援加成 | 降低对手的必杀率 | | 物防 / 魔防 | 来自防守 / 魔防，盾牌能加 | 从对手攻击里直接减掉；减到 0 就不掉血 | | 射程 | 由武器或魔法决定 | 能打到多远的对手 | | 回复量 | 魔力 ÷ 3（舍去小数）+ 回复魔法本身的回复量 + 个人特技 + 兵种特技 + 装备加成 | 用回复魔法治疗友军时回复的 HP（网友实测公式，见下） |

> 回复量公式（网友实测，欢迎验证）：回复量 = 魔力 ÷ 3 + 回复魔法本身的回复量 + 个人特技 + 兵种特技 + 装备加成。除法按火纹惯例舍去小数（满 1 才加 1）。 > 例：魔力 20 的角色用 [圣疗](skills.html#mg-12)（魔法表里回复量 10）：20 ÷ 3 = 6.67 取 6，回复 6 + 10 = 16；如果是[索绯雅](characters.html#chr-52)（个人特技「治愈的心得」+10）再装备[治愈之杖](items.html#wp-115)（+10），就是 36。 > 能加回复量的：个人特技「治愈的心得」+10；兵种特技「魔法回复+5 / +10 / +15 / +20」；装备「治愈之杖」+10；Lv 特技「信仰的恩赐+」（幸运% 几率 +30）；「圣治」偶尔回复量 +100。

武器种类与其他战斗规则

本作没有剑、枪、斧的三角克制，但每种武器各有特点：

| 武器 | 特点 | | 剑 | 追击时伤害 ×1.2 | | 枪 | 对骑兵有效（武器威力按 2 倍算） | | 斧 | 命中时至少造成 5 点伤害（对方防御再高也一样） | | 弓 | 对飞行特效（武器威力按 3 倍算） | | 拳套 | 更容易回避拳套以外的武器攻击 |

- 特效与有效：特效武器的武器威力按 3 倍算，有效按 2 倍算，两者都有时按特效 - 大型敌人的障壁：用「有效」的武器攻击战象等大型敌人，一次能打破 2 层障壁 - 装备重量：盾牌、护符等武器以外的装备也有重量，会拖慢攻速。我方回合可以随时卸下、装上装备，差一点追击不了时，先卸掉用不上的装备再打 - 伤害算出来小于 0 时都按 0 算

其他

- 移动：每回合能走几格，主要看职业 - 体格：用来抵消武器和装备的重量，重量没超过体格时不影响攻速和回避 - 重量：武器、盾牌、护符等都有重量，超出体格的部分会同时拖慢攻速和回避

> 成长率决定升级时每项能力涨不涨。想看某个角色哪项能力容易成长，去角色页看他的成长率；职业还会额外修正成长率，见职业页。
