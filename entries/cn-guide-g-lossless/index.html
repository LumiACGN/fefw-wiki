用采集卡加 Lossless Scaling 给游戏「解锁」60 帧

Switch 2 上这游戏锁 30 帧，转视角和跑图时能明显感到顿。站长自己的玩法是：主机画面走采集卡进电脑，在电脑上用 Lossless Scaling（图标是只小黄鸭，Steam 上卖几十块）做帧生成，屏幕上看到的是 60 帧甚至更高。下面是完整流程和我在用的设置，照着抄就行。

> 先说清楚：帧生成是在两帧真实画面之间「算」出中间帧，操作本身还是 30 帧响应，手感不会变成原生 60，只是画面顺滑很多。它会带来一点点延迟，对战棋这种回合制游戏基本无感，动作游戏就要自己权衡。

需要什么

- 一台能带动帧生成的电脑（近几年的独显都行，核显勉强）。站长是 RTX 30 系显卡，所以走小黄鸭；40 系及以上可以直接在 NVIDIA App 里开驱动级的帧生成（Smooth Motion），不用额外买软件，但对采集预览窗口是否生效站长没法验证，请自行测试。 - 一块 HDMI 采集卡，推荐选低延迟的型号，预览延迟直接决定手感。站长用的是 Elgato 4K S；预算有限的话，选购时认准「低延迟 / 零延迟预览」字样，几十块的通用款延迟往往有一两百毫秒，玩起来会明显拖。 - Steam 上的 Lossless Scaling。 - 一个能全屏预览采集画面的软件。站长用的是 Elgato Studio，它只认 Elgato 自家采集卡；其它品牌用各自的预览软件，或者通用的 OBS「窗口投影器」。

接线

Switch 2 底座的 HDMI 接到采集卡输入，采集卡 USB 接电脑。想同时在电视上看就用采集卡的 HDMI 直通口再接一根到电视，不需要的话不用接。

第一步：把画面放到桌面上

打开 Elgato Studio，选中你的采集卡，输入信号选 1080p 60（主机输出的是 60 Hz 信号，游戏本身 30 帧只是每帧画两次），把预览窗口拖到你要玩的显示器上并全屏。此时你看到的还是原生 30 帧。

用 OBS 的话是添加「视频采集设备」后右键预览选「窗口投影器」再全屏，效果一样。

如果显示器是 21:9 带鱼屏，画面左右会留黑边，这是正常的，游戏只有 16:9。

第二步：Lossless Scaling 的设置

打开小黄鸭，按下面这张图设，红框里是关键项。

![Lossless Scaling 设置界面](img/guides/ls-settings.webp)

| 区块 | 项目 | 设置 | 说明 | | Frame Generation | Type | LSFG 3.1 | 当前最新的帧生成模型 | | Frame Generation | Mode | Adaptive | 自适应模式，会把输出锁到下面的目标帧率 | | Frame Generation | Target | 144 | 填你显示器的刷新率（60 Hz 屏填 60，144 Hz 屏填 144） | | Frame Generation | Flow scale | 拉到最右 | 光流精度，越高中间帧越准，显卡吃得消就拉满 | | Frame Generation | Performance | 关 | 开了画质会糊，显卡带不动再开 | | Capture | Capture API | WGC | 抓取桌面窗口最稳的方式 | | Capture | Queue target | 1 | 越小延迟越低，1 就够 | | Scaling | Type | Off | 只要帧生成，不要放大 | | Rendering | Max frame latency | 2 | 默认即可 | | Rendering | HDR support / G-Sync support | 按你的显示器开 | 没有就关 | | Rendering | Draw FPS | 开 | 左上角显示「输入帧率 / 输出帧率」，方便确认生效 | | Cursor | Clip cursor | 开 | 把鼠标锁在游戏窗口里，避免误点到桌面 | | Behavior | Multi-display mode | 关 | 只有一块屏时关掉 |

第三步：启动

点右上角红色的 Scale 按钮，5 秒内切回 Elgato Studio 的全屏预览窗口（点一下它），画面会闪一下，左上角出现两个数字，就说明帧生成已经接管。要退出的话按默认快捷键 Ctrl + Alt + S。

![开启后的实际画面，左上角是输入 / 输出帧率](img/guides/ls-game.webp)

左上角「60 / 144」：左边是采集卡送进来的信号帧率 60，右边是输出到屏幕的帧率 144（站长的显示器是 144 Hz）。实际观感接近原生 60 帧。

为什么最多只像 60 帧，不能更高

帧生成只能在两张「不一样」的画面之间补中间帧。这游戏在主机上每秒只画 30 张不同的画面，采集卡把每张都送两遍凑成 60 Hz 信号，所以小黄鸭收到的连续两帧里有一半是完全相同的，在相同的两帧之间补出来的还是相同的画面。真正有动作变化的画面上限就卡在 60 帧上下，Target 填 144 只是让屏幕多显示一些重复帧，不会更顺。这是主机端 30 帧决定的天花板，换更好的显卡或采集卡都改变不了。

常见问题

- 左上角只有一个数字、或者两个数一样：帧生成没生效。多半是 Scale 之后没有及时切到游戏窗口，重新点 Scale 再切一次。 - 画面有拖影或 UI 文字抖：把 Flow scale 拉满，Performance 关掉；还不行就把 Target 降到 60。 - 感觉延迟大：Queue target 保持 1，采集软件里把预览延迟或缓冲调到最低，显示器开 G-Sync 或 FreeSync。 - 只想在电视上玩：这个方案帮不上忙，帧生成只作用于电脑屏幕上的窗口。

顺带一提

同样的方法对任何锁 30 帧的主机游戏都有效，不限于万缕千丝。录视频的话用录屏软件录这个预览窗口即可，录下来的就是帧生成后的画面；采集软件自己的录制功能录的是原生 30 帧。
