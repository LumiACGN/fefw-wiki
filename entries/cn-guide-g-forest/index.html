迷途之森与地图上没有的岛

来源摘要迷途之森（萨维隆州）走法宝箱与素材地图上没有的岛解锁条件宝箱

攻略文章 · 来源攻略 / 作者观点，未经游戏内独立核实 · 游戏版本未独立核实

来源摘要

迷途之森按蝴蝶选路，无名岛只能坐船去（赛奥朵拉篇 / 迪托利希篇 / 救世篇）：解锁条件、走法与宝箱

迷途之森（萨维隆州）

位置在帝都鞑古席翁往南，要经过阿格里斯关，关卡需要名声 LV2 以上才能通行，先把名声刷上去。四条主角线都能去。

走法

- 赛奥朵拉篇第 8 章的剧情战：按每条岔路上飞着的蝴蝶数量选路，波拿帕尔特给的提示是「1 只 → 3 只 → 2 只 → 1 只 → 3 只」，对应「左 → 右 → 左 → 左 → 右」。 - 自由行动期从世界地图进入：规则不一样，只看岔路上有没有蝴蝶，走有蝴蝶的那条。 - 走错会被送回第一个区域重来，路线本身不会变，照着再走一遍就行。

宝箱与素材

- 第 4 个区域有宝箱，里面是翠岚宝珠，使用战技时有几率获得增益，给常用战技的角色。漏拿要重新进森林，别忘。 - 第 3 部再来一次另有祝胜宝珠。 - 探索素材：毒石、魔阵石；第 3 部另有战魂石。

地图上没有的岛

在世界地图东北方的海上，只能坐船到达：赛奥朵拉篇、迪托利希篇（第 8 章出海搜寻海王凯托斯期间）和第 3 部救世篇能去。推荐 LV30。

解锁条件

- 先探索它前面的区域「潘多拉鱼巢」，岛才会出现。 - 赛奥朵拉篇：到达帕恩朵拉港都后潘多拉鱼巢开放。 - 迪托利希篇：第 8 章出海搜寻海王凯托斯时可前往。 - 救世篇：推进到第 2 区分后开放。

宝箱

岛上两个宝箱，赛奥朵拉篇和救世篇的内容不同，两次都值得去。

| 位置 | 赛奥朵拉篇 | 救世篇 | | 从歇脚处沿左侧墙壁走到底 | 厚重的异国书籍★（礼物） | 驱魔符（使用后魔防+2） | | 穿过被熊挡住的路 | 苦闷之盾★（装备） | 档案T（使用后习得暗魔法「暗黑冲击T」） |

探索素材：海星石、蓝雪石。

> 带 ★ 的两件是暂译，站内道具表尚未收录，游戏内名称核实后会更新。
