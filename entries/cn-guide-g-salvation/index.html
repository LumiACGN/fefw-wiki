第 3 部救世篇：开始前要知道的事

进入第 3 部前常见的疑问：要不要先把四个主角都打完、各篇练的角色怎么合到一起、救世篇的敌人该怎么打。

> 在以下资料基础上自行翻译、整理并更新：神攻略 wiki[《第 3 部 救世篇》](https://kamikouryaku.net/fe_banshisenkou/?%E7%AC%AC3%E9%83%A8%20%E6%95%91%E4%B8%96%E7%AF%87)。

要不要先把第 1、2 部全部通关？

不用。没通关所有主角也能开始第 3 部，没打完的主角篇、战争篇在第 3 部开始后照样可以玩。先打完的好处：

- 同伴更多，第 3 部要分多支部队、用的人也多 - 各主角合流后，他们的专属玩法（军团兵、车站等）在第 3 部也能用 - 第 1 部拿到的道具和报酬能带到第 3 部 - 战争篇不跳过通关能看到额外事件（见[地图发光点](guides.html#g-glow)的救世篇部分）

另外凯伊、迪托利希、赛奥朵拉、蕾达四人，就算战争篇是后来才打完的，培养结果也会自动「因果融合」进第 3 部。所以不必非要四人全通关再进第 3 部，只是先打完的话进第 3 部时战力更充足。

怎么进入、怎么推进

在方尖塔之间挑战与魔神巴洛尔的决战即进入第 3 部救世篇。救世篇按「区分」推进：第 1 区分为了解放鞑古席翁与达格扎一战；第 2 区分起，在期限前于世界地图上行动、强化战力。各区分流程见[主线攻略](story.html)。

会加入的同伴

第 1 区分：第 1 部通关过各自外传的话，以下几人加入：

- 谭利穆恩 - 爱娜特莉亚 - 贝特兰 - 欧露赫露

此外救世篇推进途中满足条件还有人加入（见[隐藏角色解锁](hidden.html)）。

各篇的单位合流

通关过的各篇单位会在救世篇合流。同一个角色在好几篇都练过的话，救世篇开始时可以选用哪一篇的数据；入队时等级不到 42 的，可以直接提升到 Lv42。

因果融合

- 凯伊、迪托利希、赛奥朵拉、蕾达：各自的战争篇通关后自动进行因果融合；第 3 部已经开始也没关系，通关后培养结果会反映到第 3 部的数据里 - 融合时 HP、力量、魔力、速度等每项能力取两边较高的数值，习得的技能、战技、特技也会继承 - 主角以外的角色：在因果祭坛选「同伴的因果融合」来合并培养结果

因果结合

救世篇可以在方尖塔之间进行因果结合：消耗因果碎片，把别的篇里练过的角色的能力值、特技、战技继承过来。因果碎片也用来解锁[救世的祝福](misc.html#boons)，两边都要用，合理分配。

救世篇的敌人

救世篇会出现「冥魔」和带「冥府加护」的敌人，除了魔物，人类单位里也有几种敌方专用职业（目前确认有巴伊夫·卡哈、觉者等）。有些敌人用普通攻击很难打，善用下面这些手段：

| 用途 | 手段 | | 让「冥府加护」无效 | 净化剑、救世主的个人特技、贝特兰（扎尔莫克西斯）的战技、迪托利希能习得的格斗战技「秘传·破邪铁拳」、欧若拉的加护 Lv3 | | 对冥魔有效 | 天使、星光、凯伊（欧若拉之星枪）的战技、救世主 / 蕾达 / 欧露赫露的圣焰战技 |

最省事的是救世主、净化剑、欧若拉的加护，以及蕾达和欧露赫露的圣焰战技。

各场战斗的瘴气效果（强欲、暴食、欺瞒、傲慢）和打法要点见[主线攻略](story.html)第 3 部各区分的「战斗信息」。

救世等级

> 在 Game8 英文版《How to Increase Relief Level》基础上整理。

第 3 部用「救世值 / 救世等级」代替第 1 部的名声，通关救世篇第 1 区分后开放。提升方法：

- 完成支线任务（最主要的来源，很多是缴纳素材复兴地点，复兴后又会出现新任务） - 缴纳素材复兴世界地图上的地点与设施（复兴后能用驿站、商店等） - 世界地图上的遭遇战、随机遭遇的战斗（少量） - 在剧场演出（少量，另得金币与支援值）

救世等级提升的奖励主要是各种技能的指南书，可以大幅提升技能等级，凑最上级 / 神将的转职条件很方便。
